Crane Studio
v2.4 · 2026-05-21
移動式クレーン作業を 3D で計画・検証するためのブラウザベースツールです。
現場配置、作業半径、吊荷、敷鉄板、禁止区、通路、天候予報、安全チェック、
日本式作業計画書 (PDF) の出力までを一つの画面で扱えます。

バージョン履歴

v2.4
2026-05-21
CAD Pro UI 全面リニューアル（app bar / ribbon / 左レイヤー / 右インスペクタ / ステータスバー）。左下に作業タブ（最大 3）、ライト/ダークテーマ切替、計画書モーダル刷新。
v2.3
2026-05-20
クレーンのドラッグ移動、Ctrl+クリック多選、右クリックコンテキストメニュー（旋回 / 平移 / グループ化 / 削除）、剛体グループ回転、Space で選択モード、⚙️ 設定モーダル + 📍 地点、🌤️ Open-Meteo 3 日間天気予報。
v2.0
Week 11
クレーンデータベース + 負荷チャート連動（ブーム長 × アウトリガ張出）、安全状態表示の刷新。
v1.7
Week 7
日本式作業計画書 PDF 出力 + JSON インポート/エクスポート。
v1.5
Week 6
作業半径、通路、距離測定ツール。
v1.0
Week 4
